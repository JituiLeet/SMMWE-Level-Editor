# SMMWE Level Editor

SMMWE 关卡编辑器，提供浏览器版与独立原生 Android 版（最低 Android 5.0 / API 21）。

## 网页版使用方法

打开 GitHub Pages 部署后的 `/web/` 页面即可使用，无需安装。

1. **新建 / 打开**：点击顶部「新建」创建空白草图；「打开」可导入 `.smmweproj` 工程或真实 `.swe` 关卡。
2. **选择道具**：左侧「道具图鉴」可按地形、装饰、敌人、道具、机关分类，也可搜索道具。点击道具后在中央画布点击或拖动放置。
3. **编辑画布**：画笔放置、橡皮擦删除；「平移」或按住空格拖动画布；鼠标滚轮或缩放按钮调整视图。支持撤销和重做。
4. **编辑关卡信息**：右侧可设置名称、作者、简介、标签、游戏风格、场景主题、时间限制、起点高度和终点坐标。手机/窄屏点击顶部「关卡信息」打开侧栏。
5. **调整地图**：设置宽度、高度和格子像素后点击「应用尺寸」。
6. **保存工程**：点击「保存工程」下载 `.smmweproj`，其中保留草图道具、关卡信息与导入的 SWE 数据。
7. **编辑真实 SWE**：导入 `.swe` 后选择 S2/S3/S4/S5/S8 数据层和样本中已有的 ID，再在网格上放置或擦除。完成后点击「导出 .swe」。

## 道具与兼容性说明

道具图鉴包含地形、砖块、水管、云朵、山丘、水面、岩浆、金币、钥匙、蘑菇、火焰花、敌人、门、平台、检查点等草图素材。这些是工程预览图块，不等同于已验证的 SMMWE 内部对象 ID。真实 SWE 编辑仅允许使用样本中观察到的对象 ID，并复制原始记录字段。

已知 SWE 样本中的 S1 元数据字段包括作者、简介、起点/终点位置、尺寸、游戏风格、主题和计时器。标签目前仅保存在 `.smmweproj` 工程中；没有在已验证样本中发现可确认的游戏标签字段，因此不会擅自写入 SWE。

## Android 版

Android 版使用原生 Java + Canvas，不是 WebView 套壳。GitHub Actions 可构建独立 APK。

## 构建 / 部署

网页源文件位于 `web/`，共享数据模型和 SWE 编解码位于 `core/`。GitHub Pages 工作流目前为手动触发；仓库启用 Pages 后可运行 **Deploy Web Editor** 发布网页。

SWE 外层格式与字段映射依据已知样本验证；导出文件仍建议在目标 SMMWE 游戏版本中实际导入测试。
